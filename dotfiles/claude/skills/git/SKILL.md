# Git Conventions

## Commit Sign-off

Always use the `-s` flag when running `git commit` to include a `Signed-off-by` trailer.

## Committing

Never create a commit without explicit approval from the user. Always show what will be committed and the proposed commit message first.

## History Integrity

Never override existing commits (amend, rebase, force-push) without getting explicit permission from the user.
